## idea
### 文本处理部分

---
**1.将所有的首尾可以相连的部分进行链接成一段(避免出现开头空格判断错误)**   
**2.对相同paragraph的不同line的起始位置进行逐行输入**   
**3.若存在一行的长度和段落的长度差距很大，可以被认为是第一行或者最后一行， 第一行可加空格**
**4.发现最后一行可以更改合并段落逻辑，即将该行后的段落分离开来**
**5.进行自动换行工作（将一段中的文字进行处理将原先加入的换行符去掉，首行加入原先有的空格，每行如果超过了段落边界（可以用给出的font_size计算是否超过）），则加入一个换行，最后在检查一遍最终的行数是否超过原本的行数，如果是，则将字符的font_size按原计算逻辑更新**
